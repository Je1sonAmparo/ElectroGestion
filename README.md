# ElectroGestion

Sistema de gestión para instalaciones y servicios eléctricos.

## Despliegue en Vercel

Este proyecto está configurado para desplegarse fácilmente. El archivo principal es `ElectroGestion Sistema.dc.html` y ya existe un archivo `vercel.json` configurado para que todo funcione sin tener que mover más nada.

Pasos para publicarlo:
1. Vincula este repositorio a tu cuenta de Vercel.
2. Vercel lee la configuración automáticamente.
3. El sitio queda listo en la URL que Vercel te asigne.

## Archivos principales
- `ElectroGestion Sistema.dc.html`: Interfaz del sistema (formularios de solicitud, agendas, etc).
- `support.js`: Lógica y funciones de soporte de la interfaz.
- `vercel.json`: Reglas para que Vercel sepa qué archivo cargar.
